# Проверки 0.3.1 — 1 ноября 2026

**Пройдены 65 автоматических сценариев**: сохранённые 25 сценариев версии 0.2, 24 проверки универсального режима, одна проверка миграции, 5 проверок реального интерфейса и 10 новых проверок распознавания рекламы. Среда: Google Chrome 156.0.8078.80, Playwright 1.62.1, отдельные временные профили. Пользовательские профили не использовались. Машиночитаемый отчёт — tests/results.json.

## Исправления по пользовательскому испытанию 0.3

Ошибка выбора профиля воспроизведена отдельным тестом на 0.3.0: реальный selectOption('experimental') оставлял сохранённый профиль standard. Причина — action() перерисовывал форму до считывания её значения. Аналогичный дефект был у флажков. В 0.3.1 значение фиксируется до перерисовки, поля не сбрасываются во время сохранения, устаревшие ответы настроек отбрасываются. Прежние проверки команд API не обнаруживали этот дефект окна; теперь добавлены настоящие события формы.

Новые проверки интерфейса: профиль, каждый общий/дзеновский переключатель, каждый из пяти модулей, повторное открытие окна и реальный перезапуск отдельного профиля Chrome. Общий профиль при этом остаётся standard; только dzen.profile становится experimental.

Новые DOM-проверки: возрастные и разделённые метки; верхние/боковые баннеры; рекламная публикация со ссылкой на материал Дзена (включая две ссылки с разными query/fragment на одну статью); текстовое объявление; RTB-обёртки; сохранение боковой сетки; обычные статьи и заголовки, обсуждение рекламы, скрытые рекламные шаблоны, комментарии, подписки, видео; закрытый и поздний Shadow DOM; переиспользование карточек; возврат элемента, общий выключатель и 1000 обычных карточек. Коммерческие кнопки распознаются, но не нажимаются автоматически.

Макеты воспроизводят видимые признаки пользовательских снимков, а не настоящую HTML-структуру страницы. Поддержка закрытых корней в новых макетах моделируется fixture API, как и в прежнем корпусе. Нельзя считать это подтверждением работы на закрытых корнях именно вашей версии Яндекс Браузера или подтверждением удаления всех показанных объявлений.

В тестах обновления используются намеренно маленькие контролируемые наборы исправлений; их количество в JSON не является размером поставляемой базы. Встроенный снимок содержит 761 CSS-запись и 611 сетевых правил/исключений сверх статических баз. Число правил или скрытых узлов не является измерением удалённых рекламных объявлений.

## Нагрузка

Синтетическая лента на 1000 карточек сохраняет 900 обычных карточек и скрывает 100 рекламных; повторно используемая карточка восстанавливается. Универсальная страница сохраняет 1000 обычных статей. На странице без плеера счётчик обхода кнопок адаптера Дзена — 0. Общий вспомогательный модуль не запускает периодический обход всех кнопок; поиск скрытых элементов запускается по запросу окна, исключения применяются при изменениях.

Обработка адаптера разбита на порции с бюджетом 8 мс. Измеренный пик одной порции в последнем прогоне — **59,3 мс**; бюджет не гарантирует жёсткого времени из-за отдельных DOM-операций и планирования. Это ограничение замера и повод оценить отзывчивость на компьютере мамы, а не утверждать незаметную нагрузку. Все сырые показатели сохранены в JSON.

## Пользовательское испытание и невыполненные проверки

Пользователь подтвердил частичное улучшение на Дзене с 0.3 и прислал пропущенные объявления и возврат профиля. Способ установки, версия браузера и сохранение после перезапуска по этим снимкам не установлены. Для новой 0.3.1 повторная живая проверка ещё не выполнена.

- Обновление именно до 0.3.1 подписанным CRX3, расширение разрешений при обновлении 0.2 и сохранение включённого расширения после полного перезапуска Яндекс Браузера мамы.
- Запуск сборки именно на Chromium 121 и проверка доступности закрытого Shadow DOM API в её Яндекс Браузере.
- Полные гостевые/авторизованные сценарии всех настоящих сайтов: вход, реальная почта/облако, редактор, подписки, комментарии.
- Настоящие плееры, реклама YouTube/Twitch/Rutube/VK/Дзена, измерение числа объявлений и времени видеорекламы.
- Совместная работа общего движка и адаптера на настоящем Дзене; доступ к Dzen.ru в этой среде заблокирован, ограничения не обходились.
- Отзыв реальных пользовательских разрешений и исчерпание реальной квоты браузера; поведение ошибок проверено моделированием.

Ручной список приёмки — MANUAL_TESTS.md. До прохождения обязательной проверки установки/перезапуска сборка является кандидатом для проверки, а не проверенным выпуском для мамы.

## Пакеты

ZIP включает готовые ресурсы, собственные исходники, использованные несобранные JS-исходники npm-библиотек, исходные тексты фильтров, лицензии, lock-файл и тесты. Подписанный CRX3 должен сохранять ID gbhpmimgahcdcjgppenpmllelainield. Независимая проверка подписи/CRC/совпадения файлов выполняется tools/verify-package.py (Python + cryptography; для сравнения нужны предыдущие CRX рядом с новым пакетом). Приватный ключ, node_modules и браузерный _metadata в архив не включаются. Результат проверки пакета поставляется отдельным JSON рядом с CRX/ZIP.
