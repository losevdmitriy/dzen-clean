«Дзен Чисто» помогает скрывать рекламу на обычных сайтах и содержит дополнительные правила для Дзена. В основе общей защиты — фильтры AdGuard Base и Russian Filter.

## Возможности

- **Защита на сайтах.** Блокировка поддерживаемых рекламных запросов и скрытие рекламных элементов.
- **Удобное управление.** Защиту можно выключить для отдельного сайта или вернуть ошибочно скрытый элемент.
- **Дополнительная обработка Дзена.** Отдельный адаптер распознаёт рекламные блоки; экспериментальные модули включаются пользователем отдельно.
- **Обновление исправлений.** Поддерживаемые корректирующие правила можно обновлять автоматически или вручную. Предыдущий комплект доступен для отката.
- **Локальные настройки.** Настройки и пользовательские исключения хранятся в браузере.

Результат зависит от сайта и его изменений. Часть рекламы, особенно в видео, может оставаться. Если расширение мешает работе страницы, выключите защиту для этого сайта или восстановите скрытый элемент.

## Установка

Версия 0.3.1 подготовлена для **Opera Add-ons**. Ссылка на страницу расширения появится здесь после публикации в каталоге.

Для разработки и проверки можно загрузить распакованное расширение через страницу управления расширениями браузера в режиме разработчика. Для этого нужен полный комплект из архива ниже. Такая установка предназначена для проверки: поведение и сохранение расширения после перезапуска зависят от браузера.

Проект использует Manifest V3 и рассчитан на Chromium 121 и новее. Работа в конкретной версии Opera или Яндекс Браузера требует отдельной проверки.

## Исходники и сборка

[Скачать полный комплект исходников 0.3.1](https://raw.githubusercontent.com/losevdmitriy/dzen-clean/main/dzen-clean-0.3.1-source.zip)

В архиве находятся исходный код, ресурсы, снимки правил фильтрации, лицензии, файлы сборки и lock-файл. Он соответствует комплекту, подготовленному для проверки версии, загруженной в Opera.

Часть файлов доступна прямо в репозитории:

| Путь | Содержимое |
| --- | --- |
| [src/](src/) | Исходный код расширения |
| [experimental/](experimental/) | Необязательные модули для Дзена |
| [tools/](tools/) | Инструменты сборки и проверки |
| [tests/](tests/) | Автоматические сценарии |
| [licenses/](licenses/) | Лицензии зависимостей |
| [publication/](publication/) | Материалы подготовки публикации |

Большая сгенерированная база `engine-filters/declarative/ruleset_2/ruleset_2.json` хранится **в архиве**. Поэтому для полной сборки и запуска используйте распакованный архив, а не только копию репозитория.

Для подготовки окружения нужны Node.js и pnpm; зависимости закреплены в [pnpm-lock.yaml](pnpm-lock.yaml). В проверке сборки использовались Node.js 24.22.1 и pnpm 11.25.0:

```sh
npx --yes pnpm@11.25.0 install --frozen-lockfile
node tools/bundle.mjs
```

Эти команды устанавливают зависимости и пересобирают скрипты. Они не создают автоматически опубликованную версию расширения. Фиксированные снимки фильтров уже включены в архив; загрузка новых списков изменит входные данные сборки.

## Конфиденциальность

Расширение обрабатывает сведения о странице и запросах локально для применения правил. Настройки и исключения сохраняются в браузере. При включённом автообновлении текстовые исправления загружаются с GitHub; при этом GitHub получает обычные данные сетевого запроса, включая IP-адрес.

Диагностический отчёт создаётся по действию пользователя и автоматически не отправляется издателю. Подробнее — [политика конфиденциальности](PRIVACY.md).
