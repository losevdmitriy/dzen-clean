# Дзен Чисто

Исходники расширения версии 0.3.1 для Opera Add-ons.

Полный комплект исходников, ресурсов, лицензий и файлов сборки находится в [архиве dzen-clean-0.3.1-source.zip](dzen-clean-0.3.1-source.zip). Это исходный комплект для проверки версии, загруженной в Opera.

Большая сгенерированная база `engine-filters/declarative/ruleset_2/ruleset_2.json` находится в архиве; остальные файлы доступны для просмотра в репозитории. Для полной сборки распакуйте архив.
